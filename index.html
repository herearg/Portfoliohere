Publicar tus cambios

  1. Descargá el nuevo index.html.
  2. En GitHub elegí Add file → Upload files.
  3. Subí el archivo a la raíz, reemplazando el anterior.
  4. Guardá con Commit changes y esperá la actualización de Pages.

Los cambios se guardan como borrador en este navegador. Solo se publican cuando subís el HTML a GitHub. Las imágenes que cargues se incluyen en el archivo descargado.

El editor no tiene acceso a tu cuenta. Otros visitantes solo pueden modificar su propia copia local. No guardes contraseñas ni datos privados en el sitio.
